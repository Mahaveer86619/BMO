2. Root Cause: Wrong Controller Driver

SH1106 vs SSD1306 ROOT CAUSE

The 1.3" OLED uses an SH1106 controller. The driver was written for an SSD1306 (the 0.96" standard). They are not compatible at the register/protocol level despite sharing the same I2C address and physical footprint.

PropertySSD1306 (0.96")SH1106 (1.3") — this display
Internal columns128132 (visible 128 start at offset 2)
Addressing modeHorizontal / Vertical / PagePage mode only
Buffer writeSingle 1024-byte burst8 separate page writes × 128 B
Charge pump cmd0x8D, 0x140xAD, 0x8B

Symptom: the display received the pixel-buffer bytes as command bytes, producing random dot noise and constant flicker. The I2C scan still showed 0x3C because the SH1106 ACKs all writes — it was receiving data, just misinterpreting it.

3. Fix Applied

ssd1306.c — New SH1106 Init Sequence FIXED

static const uint8_t init_cmds[] = {
    0xAE,        // Display off
    0xD5, 0x80,  // Clock divider
    0xA8, 0x3F,  // Multiplex ratio: 64 rows
    0xD3, 0x00,  // Display offset: 0
    0x40,        // Start line: 0
    0xAD, 0x8B,  // Internal DC-DC charge pump ON  ← SH1106 specific
    0xA1,        // Segment remap (mirror X)
    0xC8,        // COM scan dec  (mirror Y)
    0xDA, 0x12,  // COM pins: alternative config
    0x81, 0xFF,  // Contrast: max
    0xD9, 0x1F,  // Precharge period
    0xDB, 0x40,  // VCOM deselect level
    0xA4,        // Output follows RAM
    0xA6,        // Normal display
    0xAF,        // Display on
};

ssd1306.c — New Page-by-Page Display Function FIXED

void ssd1306_display() {
    // SH1106: 132 internal columns, visible 128 start at col offset 2.
    // Must write one page (8 rows) at a time — no horizontal mode.
    static uint8_t page_buf[SSD1306_WIDTH + 1];
    page_buf[0] = 0x40; // D/C# = 1: data stream

    for (int page = 0; page < SSD1306_HEIGHT / 8; page++) {
        ssd1306_send_cmd(0xB0 + page); // Set page address
        ssd1306_send_cmd(0x02);         // Column low  nibble (offset 2)
        ssd1306_send_cmd(0x10);         // Column high nibble (offset 2)
        memcpy(page_buf + 1, &buffer[page * SSD1306_WIDTH], SSD1306_WIDTH);
        i2c_write_blocking(i2c, ADDR, page_buf, SSD1306_WIDTH + 1, false);
    }
}

Additional Fixes FIXED

  • Removed malloc/free per frame in the old display function — replaced with a static buffer. Eliminates heap churn and a silent NULL-crash risk.
  • Added sleep_ms(100) in main.c after ssd1306_init() to let the charge pump and panel settle before the first frame.
  • Removed unused #include <stdlib.h>.
